Book Management REST API

A simple REST API built with Node.js and Express.js to manage a book inventory without using any database. All data is stored locally in a books.json file using the fs module.


Features

  • Add a new book
  • Get all books
  • Get book by ID
  • Delete book by ID
  • File-based storage using books.json
  • Middleware for logging and request enhancement
  • Input validation for required fields

Tech Stack

Node.js, Express.js, File System (fs module), Postman


API Endpoints

  • GET /books → Get all books
  • GET /books/:id → Get book by ID
  • POST /books → Add a new book
  • DELETE /books/:id → Delete book by ID

API Flow: Request → Middleware → Validation → Route Handler → File Operations → Response

RealEstate-Dapp-Sepolia – REAL Estate DApp

A decentralized application (DApp) that enables secure real estate transactions using smart contracts on the Ethereum blockchain.


The platform represents properties as NFTs and uses an escrow mechanism for secure transactions among buyers, sellers, lenders, and inspectors.


Features

  • Real Estate NFTs for ownership verification
  • Escrow smart contract system
  • Role-based access for Buyer, Seller, Lender, Inspector
  • IPFS integration using Pinata
  • Property listing and approval workflow
  • Dynamic role-based UI interactions
  • JSON Server integration for property details

Tech Stack

React (Vite), Tailwind CSS, Solidity, Hardhat, OpenZeppelin, Ethereum Sepolia Testnet, Ethers.js, IPFS, JSON Server


Workflow

  • Seller uploads metadata to IPFS
  • Property details stored in JSON Server
  • Property listed and approved
  • NFT minted after approval
  • Buyer purchases via escrow mechanism
  • Lender and Inspector verify transactions
  • Seller provides final approval

Digital Twin in Healthcare – Research Work

This research explores the concept of Digital Twin technology in healthcare, where a virtual replica of a patient or medical system is created using real-time data.


The digital twin continuously receives information from medical devices, sensors, and patient records to simulate and monitor health conditions.


Researchers use these datasets to train algorithms, test predictive models, and validate the performance of digital twin systems.


By analyzing large volumes of cardiology and radiology data, the system can identify patterns, detect anomalies, and assist healthcare professionals in making informed decisions.


Machine Learning Concepts Used

  • Supervised Learning using Decision Trees, SVMs, and Neural Networks
  • Deep Learning with CNNs for radiology image analysis
  • RNNs and Time-Series Analysis for ECG and heart-rate prediction
  • Data preprocessing, cleaning, normalization, and feature engineering
  • Predictive healthcare analysis and anomaly detection

Research Focus

  • Digital Twin simulation systems
  • Healthcare data modeling
  • Real-time monitoring systems
  • Clinical decision support
  • AI-assisted diagnostics
